# DBA-MA-SMR — Reading Portal

A six-lens reading portal for the **Design Basis for AI Governance in Critical Infrastructure**
nuclear series — the small modular reactor (SMR) facility class under deliberate **military action** (DBA-MA-SMR).

One design-basis package, framed six ways for the audiences who read it differently:

- **NRC / Regulator** — requirement-by-requirement conformance and the Commission-directed findings
- **Asset Owner-Operator** — pathway, reduced-EPZ value, siting, and obligations
- **Engineer** — source term, ASSC, dual design basis, and the adequacy / V&V arguments
- **Environmentalist** — source term → dose → EPZ, and the conditionality of the relaxation
- **Community** — plain-language emergency planning zone, siting, and monitoring
- **National Security** — the military-action extension: threat, denial, counter-UAS, cyber, and the DoD/IC pathway

The site is a single self-contained `index.html` (no build step, no dependencies), served via GitHub Pages.

Instrument links resolve to versioned **Zenodo** deposits (CC BY 4.0) as each is published;
designators are shown in the interim. Concept DOI (all versions): https://doi.org/10.5281/zenodo.21430410
